# MSc_DV_CC
Data visulisation course work on digial currency

this project uses jupyter notebook to analyze data and plot graphs.

Visualisation tools used (these lib should be installed): 
    Plotnine
    Networkx + Gephi (software) , details about Gephi can be found in 

Data used are from:
    1. World bank for indicatiors
    2. CoinMarketCap & CoinGecko for more complete cryptocurrency transaction volume
    3. Blockchair for daily bitcoin transaction history on 2026-01-01


Scripts in the file:
    task1.ipynb and task2.ipynb  can be used to generate analysis of impact on indicators
    task3.ipynb  can be used to analyze 2026-01-01 transaciton data.

Corrsponding data are stored in different task folder.
